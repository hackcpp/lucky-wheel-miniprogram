# 幸运转盘 · 微信小程序

> 帮选择困难症决定「今天吃什么、玩什么」。

一个**纯前端、零后端、零网络请求**的微信小程序。所有数据存在本机，打开即用，不收集任何用户信息。

---

## 功能

| 功能 | 说明 |
| --- | --- |
| 三套分类 | 「吃什么」「玩什么」「自定义」，Tab 一键切换 |
| 转盘抽选 | 点击开始，转盘缓动旋转后停在结果扇区 |
| 权重设置 | 每个选项可设 1–5 级权重，权重越高越容易被抽中 |
| 选项管理 | 增 / 删 / 调权重，自动保存到本地 |
| 结果卡片 | 弹出抽中结果，支持「再来一次」 |
| 分享 | 支持转发好友与分享朋友圈 |

> 说明：权重只影响被抽中的概率，转盘扇区始终等分绘制。若按权重画成不等分，小扇区会窄到看不清文字，体验反而更差。

## 快速开始

```bash
git clone https://github.com/hackcpp/lucky-wheel-miniprogram.git
```

1. 用[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)导入项目根目录
2. 在 `project.config.json` 中填入自己的 AppID（或选「测试号」）
3. 基础库建议 ≥ 2.20.1（确保 `getWindowInfo` 可用，规避已废弃的 `getSystemInfoSync` 告警）
4. 直接编译运行，无需安装依赖，也不需要「构建 npm」

## 隐私与合规

本小程序**不发起任何网络请求**，不接入服务器，不采集、不上传任何用户数据。所有选项仅存储于本机，卸载即清除。

因此无需配置服务器域名白名单、无需 ICP 备案、无需隐私政策弹窗，适合以个人主体注册后提交审核（类目建议选「工具」）。
